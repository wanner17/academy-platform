학원 플랫폼 관리자 운영 매뉴얼

처음 시작하는 관리자를 위한 단계별 시스템 운영 및 설정 가이드

01 시스템 소개

본 플랫폼은 복잡한 학원 운영 업무(기본 설정, 강좌 등록, 요일별 시간표 빌더, 강사진 소개, 학생 출결 및 알림 피드)를 직관적인 SaaS 어드민 환경에서 통합 제어할 수 있도록 설계된 최고급 학원 통합 관리 솔루션입니다.

학원 메인 랜딩 페이지 - 학생/학부모용 화면
💡
학부모가 느끼는 첫인상 메인 랜딩 페이지에는 실시간 실적 카운터, 강좌 추천 퀴즈, 후기 슬라이더 등 입학 결정을 유도하는 마케팅 요소들이 포함되어 있으며, 모두 관리자 페이지의 실시간 DB 데이터와 상호 연동되어 동작합니다.

02 시스템 시작 및 로그인

관리자 전용 대시보드에 접근하기 위한 로그인 방법 및 초기 접속 정보입니다.

관리자 로그인 화면
  • 01

    관리자 페이지 접속

    인터넷 주소창에 http://localhost:3000/admin 주소를 입력하여 관리자 페이지로 이동합니다.

  • 02

    로그인 정보 입력

    등록된 관리자 인증 계정 정보를 입력합니다.
    기본 테스트 관리자 계정:
    • 이메일: admin@example.com
    • 비밀번호: password1234

⚠️
비밀번호 보안 권장사항 운영 대시보드는 원격 DB 권한을 포함하고 있으므로, 최초 로그인 성공 후 마이페이지나 데이터베이스 설정을 통해 보안 강도가 높은 비밀번호로 즉시 변경해 주시기 바랍니다.

03 관리자 대시보드 개요

로그인 완료 후 나타나는 관리자 홈 화면으로, 학원의 모든 세부 기능을 한눈에 조망하고 관리할 수 있습니다.

어드민 핵심 기능 제어 카드 목록
⚡
원클릭 네비게이션 카드 UI 대시보드의 모든 타일형 카드는 마우스를 올렸을 때 금빛(Gold) 보더 라인 하이라이트와 리프트 애니메이션을 제공하여 편안한 업무 제어를 돕습니다. 원하는 관리 항목을 클릭해 해당 페이지로 즉시 이동할 수 있습니다.

04 강좌 및 커리큘럼 관리

학원의 핵심인 교육 과정과 주차별 수업 내용을 상세히 작성하고 공개 여부를 결정합니다.

등록된 정규 강좌 리스트
  • 01

    강좌 정보 기입

    강좌 추가 버튼을 클릭해 과목(수학/영어 등), 강좌 명, 대상 학년(초등/중등/고등), 유형(내신반/수능반) 및 강사 매핑 정보를 기입합니다.

  • 02

    실시간 공개 노출 설정 (Active Toggle)

    해당 강좌를 학생용 찾기 퀴즈나 공개 강좌 소개 리스트에 노출하려면 공개 상태(Active)를 체크하여 활성화 상태로 저장해야 합니다.

05 강사진 관리

학부모와 학생들이 가장 중요하게 신뢰도를 판단하는 강사진의 역량, 사진, 이력을 관리합니다.

강사 리스트 및 노출 순서 편집 화면
  • 01

    소속 강사 등록

    이름, 대표 교육 과목(수학, 영어 등) 및 강사의 특징을 한눈에 알 수 있는 한 줄 슬로건과 상세 경력을 작성합니다.

  • 02

    노출 순서 지정 (Order 필드)

    메인 홈페이지 강사진 소개란에 배치될 정렬 순서를 지정할 수 있습니다. 숫자가 낮을수록(예: 1) 최상단에 배치됩니다.

06 요일별 시간표 관리

요일별, 교실별 수업 시간 배치를 그리드 뷰를 통해 일목요연하게 조율하는 가이드입니다.

학생/학부모들이 조회하는 요일별 시간표 화면
📅
시간표와 과목 필터 연계 원리 관리자가 DB에 시간표 일정을 하나라도 등록하면, 사용자 시간표 페이지 상단에 해당 과목별(수학/영어 등) 필터 버튼이 실시간으로 자동 생성됩니다. 따라서 별도의 필터 태그 설정 없이 수업 데이터 등록만으로 다이내믹 시간표가 구현됩니다.

07 학생 관리 & 실시간 출결 체크

학원에 등록된 학생들을 생성하고, 매일매일의 출결 상태(출석, 결석, 지각)를 입력하여 학부모 안심 서비스를 실현합니다.

  • 01

    학생 정보 카드 조회

    학생 이름, 소속 학교명, 학년 및 비상 연락처(학부모 연락처)가 매핑된 목록을 확인합니다.

  • 02

    실시간 출결 현황 기록

    해당 요일의 수업별로 출석 대장을 열어 단 몇 번의 터치로 출결 기록을 마킹할 수 있으며, 이 기록은 실시간으로 학생 전용 포털의 개인 캘린더에 동기화됩니다.
