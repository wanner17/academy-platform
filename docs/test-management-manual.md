# 테스트 관리 기능 매뉴얼

> 수업관리 > 테스트 페이지 기준으로 작성된 매뉴얼입니다.

---

## 1. 테스트 구분 관리

### 개요
테스트 결과를 종류별로 분류할 수 있는 구분을 만들고 색상을 지정할 수 있습니다.  
구분은 **강사별로 분리**되어 관리됩니다 (본인이 만든 구분만 보임).

### 구분 추가
1. `수업관리 > 해당 수업 > 테스트` 진입
2. 우측 사이드바 **"테스트 구분 관리"** 섹션에서 구분명 입력
3. 색상 팔레트 클릭해서 색상 선택
4. **추가** 버튼 클릭

### 구분 삭제
- 목록 우측 **삭제** 클릭 → 확인
- 해당 구분이 연결된 테스트들의 구분값은 자동으로 초기화됩니다 (삭제되지 않음)

---

## 2. 테스트 결과 입력

### 점수 입력 방식
점수는 **획득점수 / 만점** 두 필드로 나눠 입력합니다.

| 입력 예시 | 저장 형식 |
|-----------|-----------|
| 획득: 85, 만점: 100 | `85/100` |
| 획득: 18, 만점: 20 | `18/20` |
| 획득: 9, 만점: (비워둠) | `9` |

- 만점을 비워두면 획득점수만 저장됩니다.
- 숫자만 입력 가능합니다 (텍스트 불가).

### 구분 선택
- 등록된 구분 목록 중에서 선택
- 선택 시 해당 구분의 색상 점(●)이 미리보기로 표시됨
- 비워둬도 저장 가능 (구분 없음)

### Pass / Fail
테스트 통과 여부를 별도로 기록할 수 있습니다.

| 선택값 | 표시 |
|--------|------|
| 통과 (Pass) | 초록 뱃지 "통과" |
| 미통과 (Fail) | 빨간 뱃지 "미통과" |
| 해당없음 (비워둠) | `-` |

---

## 3. 점수 추이 그래프

### 사용 방법
1. `수업관리 > 해당 수업 > 테스트` 하단 **"점수 추이 그래프"** 섹션
2. **학생 선택** 드롭다운에서 학생 선택
3. **구분 선택** 드롭다운에서 보고 싶은 구분 선택 (미선택 시 전체 구분 표시)

### 그래프 읽는 법
- X축: 테스트 날짜
- Y축: 점수 비율 (0% ~ 100%)
  - `85/100` → 85%로 환산
  - `18/20` → 90%로 환산
  - 만점 없이 숫자만 있는 경우 그 숫자를 %로 표시
- 구분별로 색상이 다른 선으로 구분됨

## 4. 엑셀 일괄 등록

### 양식 다운로드
1. `수업관리 > 해당 수업 > 테스트` 우측 **"엑셀 일괄 등록"** 섹션
2. **양식 다운로드** 버튼 클릭
3. `테스트_일괄등록_양식.xlsx` 파일 저장됨

### 양식 컬럼 설명

| 컬럼 | 필수 | 설명 | 예시 |
|------|------|------|------|
| 학생 | ✅ | 수업에 등록된 학생 이름 (정확히 일치해야 함) | 홍길동 |
| 테스트명 | ✅ | 테스트 이름 | 5월 문법 테스트 |
| 점수 | ✅ | 획득/만점 형식 | 85/100 |
| 구분 | ⬜ | 등록된 구분명 (정확히 일치해야 함) | 단어 테스트 |
| P/F | ⬜ | pass 또는 fail 입력 (빈칸 가능) | pass |
| 일시 | ✅ | 테스트 날짜/시간 | 2024-05-10 14:00 |
| 메모 | ⬜ | 메모 내용 | 재시험 예정 |
| 공개 | ⬜ | Y 또는 N (기본값 Y) | Y |

### 업로드 방법
1. 양식 작성 후 파일 저장
2. **드래그앤드롭** 또는 **클릭해서 파일 선택**
3. 미리보기 테이블에서 오류 행 확인
   - 빨간 배경: 오류 (학생 없음, 구분 없음 등) → 해당 행만 제외하고 등록
   - 초록 "정상": 등록 가능
4. **N건 등록** 버튼 클릭

### 오류 유형

| 오류 메시지 | 원인 | 해결 방법 |
|-------------|------|-----------|
| 학생 없음: OOO | 이름이 DB 학생과 불일치 | 학생 이름 정확히 입력 |
| 구분 없음: OOO | 구분명이 등록된 구분과 불일치 | 구분 관리에서 해당 구분 추가 |
| 학생 필수 | 학생 컬럼이 비어있음 | 학생 이름 입력 |
| 테스트명 필수 | 테스트명 컬럼이 비어있음 | 테스트명 입력 |
| 점수 필수 | 점수 컬럼이 비어있음 | 점수 입력 |
| 일시 필수 | 일시 컬럼이 비어있거나 형식 오류 | `YYYY-MM-DD HH:MM` 형식으로 입력 |

## 5. 테스트 목록 화면 설명

| 컬럼 | 설명 |
|------|------|
| 테스트명 | 테스트 이름 |
| 구분 | 색상 점 + 구분명 |
| 점수 | `획득/만점` 형식 |
| P/F | 통과/미통과 뱃지 |
| 일시 | 테스트 날짜 |
| 학생 | 학생 이름 |
| 공개 | 학생 앱 노출 여부 |

### 검색/필터
- 검색어: 테스트명, 학생명, 점수, 메모 등 키워드 검색
- 학생 필터: 특정 학생의 테스트만 표시
